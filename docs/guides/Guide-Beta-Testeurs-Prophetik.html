1. Bienvenue

Merci de participer à la bêta Prophetik. Vous testez une version non publique, réservée à un groupe restreint.

  • Installez via TestFlight (Apple) ou le test fermé Google Play (Android).
  • Utilisez l'app normalement et signalez les anomalies à [EMAIL_SUPPORT].
  • Ne partagez pas les liens d'invitation hors du groupe autorisé.

Partie A — iPhone / iPad (TestFlight)

A.1 Installation

  1. Installez TestFlight depuis l'App Store (éditeur Apple).
  2. Ouvrez le courriel d'invitation « Vous avez été invité à tester Prophetik » et touchez Voir dans TestFlight.
  3. Ou ouvrez le lien direct : [LIEN_TESTFLIGHT]
  4. Dans TestFlight : Accepter → Installer.
  5. L'icône Prophetik apparaît sur l'écran d'accueil.

A.2 Mises à jour

Ouvrez TestFlight → Prophetik → Mettre à jour lorsqu'une nouvelle build est disponible.

A.3 Achats test (optionnel)

Compte Sandbox Apple : Réglages → App Store → Compte sandbox (en bas). Utilisez le compte test fourni par Prophetik — pas votre Apple ID principal. Renouvellement mensuel sandbox ≈ 5 minutes.

A.4 Dépannage iOS

ProblèmeSolution

« Update required »Installer la dernière build TestFlight

Partie B — Android (Test fermé Google Play)

B.1 Installation

  1. Sur votre téléphone, ouvrez : [LIEN_GOOGLE_PLAY_CLOSED]
  2. Connectez-vous avec le compte Google autorisé.
  3. Touchez Devenir testeur / Become a tester.
  4. Attendez 15–30 minutes si l'accès ne s'active pas tout de suite.
  5. Touchez Télécharger sur Google Play et installez Prophetik.

B.2 Mises à jour

Via le Google Play Store, comme une application normale.

B.3 Dépannage Android

ProblèmeSolution
App non disponibleVérifier inscription testeur ; bon compte Google ; attendre 30 min
Lien invalideOuvrir dans Chrome ; se reconnecter au compte Google
Ancienne versionDésinstaller → réinstaller depuis la fiche testeur Play Store

3. Premiers pas

  1. Connexion avec votre compte Prophetik.
  2. Accepter les notifications (défis, résultats).
  3. Rejoindre le groupe de test indiqué par l'équipe.
  4. Parcours : Aujourd'hui → Défi → Classement → Live.

4. Signaler un bug

Courriel à [EMAIL_SUPPORT] avec : plateforme + modèle + version OS, version Prophetik, étapes de reproduction, captures d'écran.
