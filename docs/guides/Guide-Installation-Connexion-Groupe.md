## En bref (3 étapes)

1. **Installer** Prophetik depuis le lien ci-dessus.
2. **Se connecter** avec son numéro de mobile (code SMS).
3. **Rejoindre le groupe** avec le **code d’invitation à 8 caractères** (ou en scannant le QR fourni par l’administrateur du groupe).

## 1. Installer l’application

### Android

1. Ouvrez le lien Play Store sur votre téléphone.
2. Touchez **Installer**.
3. Ouvrez **Prophetik** une fois l’installation terminée.

### iPhone / iPad

**Si le lien App Store est disponible :** recherchez **Prophetik** ou ouvrez `[LIEN_IOS]`, puis **Obtenir / Installer**.

**Sinon (TestFlight) :**

1. Installez **TestFlight** depuis l’App Store (éditeur : Apple).
2. Ouvrez https://testflight.apple.com/join/4DAKMFcD sur votre iPhone/iPad.
3. Dans TestFlight : **Accepter** → **Installer** Prophetik.

## 2. Se connecter (SMS)

À la première ouverture :

1. Touchez **Continuer avec SMS** (ou équivalent sur l’écran d’accueil).
2. *(Optionnel)* Entrez votre **prénom** — il apparaîtra dans les classements.
3. Entrez votre **numéro de mobile** (ex. `5145551234` — le format international est géré automatiquement).
4. Touchez **Envoyer le code**.
5. Consultez vos **SMS** : le code provient de **capitaine.firebaseapp.com** — c’est normal, c’est le service d’authentification officiel de Prophetik.
6. Saisissez le **code à usage unique** reçu par SMS.
7. Touchez **Confirmer**.

Vous êtes connecté. Un écran de bienvenue s’affiche si c’est votre première connexion.

---

## 3. Rejoindre un groupe

L’administrateur du groupe vous communique :

- un **code d’invitation** (8 caractères, ex. `AB12CD34`), **ou**
- un **QR code** à scanner depuis l’app.

### Juste après la connexion

Sur l’écran **Bienvenue** :

1. Touchez **Rejoindre un groupe**.
2. Entrez le code **ou** touchez **Scanner un QR** et autorisez la caméra si demandé.
3. Touchez **Rejoindre le groupe**.

### Plus tard (déjà connecté)

1. Ouvrez le menu (**☰**) → **Groupes**.
2. Touchez **Rejoindre**.
3. Entrez le code ou scannez le QR.

### Code d’invitation — format

- **8 caractères** : lettres **A à Z** (sans **O**) et chiffres **1 à 9** (sans **0**).
- Exemple valide : `K7MNP3R2`

### Après avoir rejoint

- Vous apparaissez dans la liste des membres du groupe.
- Si vous étiez déjà actif dans un autre groupe, le nouveau groupe peut être rejoint en **mode inactif** : activez-le quand vous serez prêt à y jouer (message proposé à l’écran).
- Définissez un **groupe favori** (icône ★) pour le voir en premier sur l’accueil.

## Dépannage rapide

| Problème | Solution |
|----------|----------|
| Pas de SMS reçu | Vérifiez le numéro ; attendez 1–2 min ; relancez **Envoyer le code** ; vérifiez les filtres SMS / blocage. |
| Code SMS refusé | Vérifiez qu’il n’y a pas d’espace ; renvoyez un nouveau code si la session a expiré. |
| Code de groupe invalide | 8 caractères exactement ; pas de **O** ni **0** ; demandez un nouveau code à l’admin. |
| QR ne scanne pas | Autorisez la caméra dans les réglages du téléphone ; saisissez le code manuellement. |
| « Connexion requise » | Reconnectez-vous via **Continuer avec SMS**. |
| Android : badge « Beta » | Peut apparaître si l’app a été installée via un test fermé ; la version Play Store publique ne devrait pas l’afficher après réinstallation depuis le lien production. |
