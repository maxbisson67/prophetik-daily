# Partie A — iPhone / iPad (TestFlight)

## A.1 Qu'est-ce que TestFlight ?

**TestFlight** est l'application officielle d'Apple pour installer des versions bêta. Vous devez :

1. Recevoir une **invitation** (courriel ou lien public du groupe interne).
2. Installer **TestFlight** depuis l'App Store.
3. Accepter l'invitation et installer **Prophetik**.

## A.2 Étapes d'installation (iOS)

### Étape 1 — Vérifier votre courriel

- Apple enverra l'invitation à l'adresse que l'équipe Prophetik a enregistrée.
- Vérifiez les **courriers indésirables** si vous ne voyez rien sous 24 h.

### Étape 2 — Installer TestFlight

1. Ouvrez l'**App Store** sur votre iPhone/iPad.
2. Recherchez **TestFlight** (éditeur : Apple).
3. Installez l'application **TestFlight**.

### Étape 3 — Accepter l'invitation Prophetik

**Option A — Courriel d'invitation**

1. Ouvrez le courriel **« Vous avez été invité à tester Prophetik »** (ou similaire).
2. Touchez **View in TestFlight** / **Voir dans TestFlight**.
3. TestFlight s'ouvre → touchez **Accept** / **Accepter**.
4. Touchez **Install** / **Installer**.

**Option B — Lien direct**

1. Ouvrez ce lien sur votre iPhone/iPad : `[LIEN_TESTFLIGHT]`
2. Suivez les instructions à l'écran dans TestFlight.
3. Installez **Prophetik**.

### Étape 4 — Lancer l'app

- L'icône **Prophetik** apparaît sur l'écran d'accueil (comme une app normale).
- Les **mises à jour bêta** arrivent via TestFlight ; ouvrez TestFlight périodiquement ou activez les notifications TestFlight.

## A.3 Mettre à jour la bêta (iOS)

1. Ouvrez **TestFlight**.
2. Sélectionnez **Prophetik**.
3. Si une nouvelle build est disponible, touchez **Update** / **Mettre à jour**.

## A.4 Tester les achats (iOS — optionnel)

Si vous testez les abonnements :

1. Sur l'iPhone : **Réglages → App Store → Compte sandbox** (tout en bas).
2. Connectez-vous avec le **compte Sandbox** fourni par l'équipe Prophetik (pas votre Apple ID principal).
3. Dans l'app, ouvrez **Abonnement** et effectuez un achat test.
4. Les renouvellements sandbox sont **accélérés** (ex. mensuel ≈ 5 minutes).

> **Important :** n'utilisez pas votre vraie carte bancaire pour les tests sandbox.

## A.5 Dépannage iOS

| Problème | Solution |
|----------|----------|
| Pas de courriel d'invitation | Confirmez l'adresse courriel auprès de `[EMAIL_SUPPORT]` ; vérifiez les spams. |
| « Unable to install » | Redémarrez l'iPhone ; libérez de l'espace ; réessayez via TestFlight. |
| L'app se ferme au lancement | Désinstallez Prophetik, réinstallez depuis TestFlight ; signalez le crash avec modèle iOS. |
| « Update required » | Installez la **dernière build** disponible dans TestFlight. |
| TestFlight demande un code | Utilisez le lien `[LIEN_TESTFLIGHT]` ou demandez une réinvitation. |

# Partie B — Android (Test fermé Google Play)

## B.1 Qu'est-ce que le test fermé ?

Google Play permet à Prophetik de distribuer une version bêta à une **liste restreinte** de testeurs. Vous devez :

1. Avoir un **compte Google** accepté dans la liste de test.
2. Ouvrir le **lien d'inscription au test**.
3. Installer **Prophetik** depuis le **Google Play Store** (pas un fichier APK externe, sauf indication contraire).

## B.2 Étapes d'installation (Android)

### Étape 1 — Vérifier votre compte Google

- L'adresse Gmail utilisée sur votre téléphone doit correspondre à celle **autorisée** par l'équipe Prophetik.
- Si vous utilisez plusieurs comptes Google sur l'appareil, notez lequel est actif dans le Play Store.

### Étape 2 — Rejoindre le programme de test

1. Sur votre téléphone Android, ouvrez ce lien : `[LIEN_GOOGLE_PLAY_CLOSED]`
2. Connectez-vous avec le **compte Google autorisé**.
3. Touchez **Devenir testeur** / **Become a tester**.
4. Attendez quelques minutes (parfois jusqu'à **15–30 min**) que l'accès se propage.

### Étape 3 — Installer depuis Google Play

1. Sur la même page, touchez **Télécharger sur Google Play** / **Download it on Google Play**.
2. Ou ouvrez le **Play Store**, recherchez **Prophetik**.
3. Installez l'application.

> **Note :** tant que vous n'êtes pas inscrit comme testeur, l'app peut apparaître **non disponible** dans votre région ou pays.

### Étape 4 — Lancer l'app

- Ouvrez **Prophetik** depuis le tiroir d'applications.
- Connectez-vous avec votre compte habituel Prophetik (courriel / lien magique).

## B.3 Mettre à jour la bêta (Android)

- Les mises à jour passent par le **Google Play Store**, comme une app normale.
- Activez **Mise à jour automatique** pour Prophetik si possible.

## B.4 Tester les achats (Android — optionnel)

- Les achats test utilisent votre compte Google configuré pour les **tests de licence** ou un compte testeur Play Console.
- Suivez les instructions spécifiques envoyées par `[EMAIL_SUPPORT]` si des abonnements sont à valider.

## B.5 Dépannage Android

| Problème | Solution |
|----------|----------|
| « L'application n'est pas disponible » | Vérifiez que vous êtes **testeur inscrit** ; attendez 30 min ; bon compte Google. |
| Le lien ne fonctionne pas | Copiez-collez `[LIEN_GOOGLE_PLAY_CLOSED]` dans Chrome ; déconnectez-vous/reconnectez-vous au compte Google. |
| Ancienne version installée | Play Store → Prophetik → **Désinstaller** → réinstaller depuis la fiche testeur. |
| Erreur d'installation | Libérez de l'espace ; videz le cache du Play Store (Paramètres → Apps → Google Play Store → Stockage). |

## 5. FAQ

**Puis-je partager l'app avec un ami ?**  
Non. Les liens TestFlight et Google Play fermé sont réservés aux testeurs invités.

**Dois-je désinstaller la version App Store ?**  
Si vous aviez une ancienne version, désinstallez-la avant d'installer la bêta pour éviter les conflits.

**La bêta expire-t-elle ?**  
TestFlight : les builds expirent après ~90 jours (Apple). Google Play : selon la durée du test configurée par Prophetik.

**Mes données sont-elles en production ?**  
Oui, la bêta utilise généralement l'environnement **réel** (groupes, défis). Évitez les actions que vous ne voudriez pas garder en production.
