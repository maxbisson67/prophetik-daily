1. Installer l’application

Android

  1. Ouvrez le lien Play Store sur votre téléphone.
  2. Touchez Installer.
  3. Ouvrez Prophetik.

iPhone / iPad

App Store (si publié) : recherchez Prophetik ou ouvrez [LIEN_IOS].

TestFlight (en attendant) :

  1. Installez TestFlight depuis l’App Store.
  2. Ouvrez le lien TestFlight Prophetik.
  3. Accepter → Installer.

2. Se connecter (SMS)

  1. À l’ouverture, touchez Continuer avec SMS.
  2. (Optionnel) Entrez votre prénom.
  3. Entrez votre numéro de mobile (ex. 5145551234).
  4. Touchez Envoyer le code.
  5. Consultez vos SMS — le message peut provenir de capitaine.firebaseapp.com (normal).
  6. Saisissez le code reçu et touchez Confirmer.
🔒 Les SMS d’authentification proviennent du service officiel Firebase utilisé par Prophetik (capitaine.firebaseapp.com).

3. Rejoindre un groupe

L’administrateur vous donne un code à 8 caractères (ex. K7MNP3R2) ou un QR code.

Première connexion

  1. Sur l’écran Bienvenue, touchez Rejoindre un groupe.
  2. Entrez le code ou touchez Scanner un QR (autorisez la caméra).
  3. Touchez Rejoindre le groupe.

Déjà connecté

  1. Menu ☰ → Groupes → Rejoindre.
  2. Code ou QR comme ci-dessus.

Format du code : 8 caractères — lettres A–Z (sans O) et chiffres 1–9 (sans 0).

Dépannage rapide

ProblèmeSolution
Pas de SMSVérifier le numéro ; attendre 1–2 min ; renvoyer le code
Code SMS refuséPas d’espace ; renvoyer un code si expiré
Code groupe invalide8 caractères ; pas de O ni 0 ; redemander à l’admin
QR ne fonctionne pasAutoriser la caméra ; saisir le code à la main
